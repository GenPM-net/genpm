01 — Concepto

Anclado.

Un paquete GenPM es confiable porque está anclado a un commit: lo que revisaste es exactamente lo que se instala. La identidad aplica la misma regla a la forma. Cada elemento se apoya en una retícula de líneas de 1 px, nada flota, y el color solo aparece cuando lleva información.

Tesis

El blanco es el estado limpio del repositorio antes de inyectar. Lo que se añade (código, reglas, conexiones) se ve con precisión porque no hay nada más compitiendo.

PrincipiosCuatro reglas que deciden cualquier pantalla nueva.
regla · elevación

Línea, no sombra

La profundidad se dibuja con bordes de 1 px y espacio. Hay dos niveles de borde y ningún tercero. Una tabla de un millón de filas y una tarjeta de paquete usan el mismo lenguaje, así la interfaz escala sin acumular ruido.

regla · color

El color es dato

La marca es tinta sobre blanco. Verde, violeta y cian existen solo para las tres capas: Code, Context y Connections. Ámbar y rojo, solo para estados. Si un color no codifica algo, no se usa.

regla · imagen

El comando es la imagen

Sin fotos de stock ni ilustraciones decorativas. Las imágenes de GenPM son comandos, árboles de archivos, SHAs y diagramas de injerto reales, en HTML copiable.

regla · movimiento

Un solo elemento vivo

El caret ▍ es lo único que se anima por sí mismo: parpadea en el logo del hero. Todo lo demás se mueve solo como respuesta a una acción (150–200 ms, ease-out).

What gets injected

Three layers. One commit.

Every package carries code, the rules your AI needs to use it, and the MCP servers it talks to. All of it passes through the same SHA check.

Code you own

Lands in src/, not in node_modules. You see it in your diff, edit it, commit it.

Context your AI gets

An AGENTS.md per module, loaded only when your agent works in that folder.

Connections, ready

The MCP servers a module needs, declared in its manifest. Added only with your consent.

    @core/billing

    Subscription checkout, customer portal and an idempotent webhook handler backed by a stripe_events table. Gate features with hasEntitlement(user, feature).

    Adapters for Hono and Next.js route handlers. Requires @core/db and @core/auth, which GenPM resolves for you.

    ~1.1k tokens→ src/lib/billing/AGENTS.md→ .cursor/rules/billing.mdc

    This is exactly what your AI will read when it works in src/lib/billing. Nothing else is added to its context.

    # @core/billing

## Integración
- Mount the webhook at POST /api/billing/webhook.
- Verify the Stripe signature before parsing the body.
- Gate features with hasEntitlement(user, feature).
  Never read the subscriptions table directly.

## Datos
- Tables live in schema/billing.ts. Do not edit
  tables owned by @core/auth or @core/db.

## No hacer
- Do not store card data or raw PaymentMethods.
- Do not hardcode price IDs; read STRIPE_PRICE_* from env.
