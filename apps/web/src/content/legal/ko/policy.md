이 정책은 패키지를 설치하는 모든 사람과 패키지 규칙을 읽는 AI 에이전트에게 GenPM을 안전하게 유지하기 위한 것입니다. [서비스 약관](/terms)의 일부이며, 규정(EU) 2022/2065(디지털서비스법, DSA)에 따른 콘텐츠 관리 규칙을 정합니다. 내용이 다를 경우 스페인어판이 우선합니다.

## 1. 허용되지 않는 것

- 악성 코드, 자격 증명 탈취 프로그램, 암호화폐 채굴기, 데이터를 외부로 빼돌리는 코드.
- 사용자의 지시를 무시하게 하거나, 사용자에게 작업을 숨기거나, 에이전트에게 다른 곳으로 데이터를 보내게 하는 AI 규칙(*프롬프트 인젝션*).
- 프로젝트를 열거나 설치할 때 자동으로 실행되는 파일: 설치 스크립트, `.npmrc`, `.envrc`, `.vscode/tasks.json`, git 훅 등.
- 시크릿: API 키, 토큰, 개인 키(취소된 것 포함).
- 제3자의 지식재산권이나 산업재산권을 침해하는 콘텐츠, 그 밖의 불법 콘텐츠.
- 타이포스쿼팅, 다른 게시자나 브랜드 사칭.
- 스팸, 빈 패키지, 이름 선점.

## 2. 탐지 방법

- **자동:** 모든 버전을 게시할 때 스캔하고, 설치할 때 CLI가 다시 스캔합니다(자동 실행 파일, 시크릿, 안전하지 않은 경로, 심볼릭 링크, AI 규칙의 프롬프트 인젝션 징후).
- 누구나 할 수 있는 **신고**(§4 참고).
- **사람의 검토:** 표시된 버전은 검토 대상이 되며, 사람이 영업일 기준 24시간 안에 검토하기 전까지 설치할 수 없습니다. 최종 철회를 자동 수단만으로 결정하지 않습니다.

## 3. 가능한 조치

심각도에 따라 버전을 검토 대상으로 지정, 철회(*yank*), 패키지 전체나 스코프를 검토 대상으로 지정, [/security/advisories](/security/advisories)에 보안 권고 게시, 중대하거나 반복된 위반 시 계정 정지 등의 조치를 합니다. 조치는 비례성을 지키며 모든 당사자의 권리와 이익을 고려합니다.

## 4. 콘텐츠 신고 방법

계정이 없어도 누구나 패키지를 신고할 수 있습니다.

- 패키지 페이지의 **신고** 버튼으로(GitHub 로그인 필요), 또는
- 제목을 "[REPORT]"로 하여 {{email}}으로 이메일을 보내서.

조치를 위해 다음을 포함해 주세요. 패키지와 버전(또는 URL), 불법이거나 이 정책에 위반된다고 보는 이유, 이름과 이메일, 알고 있는 범위에서 정보가 정확하고 완전하다는 진술. GenPM 자체의 취약점은 [/security](/security)를 참고하세요.

접수를 확인하고 결정과 구제 수단을 알려 드립니다. 사람의 생명이나 안전을 위협하는 범죄의 징후를 발견하면 관할 당국에 알립니다(DSA 제18조).

## 5. 여러분의 콘텐츠에 조치하는 경우

여러분의 패키지를 철회하거나 제한하거나 계정을 정지하는 경우, 조치 내용, 이유, 근거가 된 사실, 자동 수단의 사용 여부, 적용한 규칙이나 조항을 담은 이유서(DSA 제17조)를 보냅니다.

**이의 제기:** 6개월 이내에 제목을 "[APPEAL]"로 하여 {{email}}으로 이메일을 보내면 결정의 재검토를 요청할 수 있습니다. 자동 스캔이 아닌 사람이 검토하며, 이유를 밝혀 답변합니다. 법원에 소를 제기할 수도 있습니다.

## 6. 투명성

보안 권고는 [/security/advisories](/security/advisories)와 JSON 피드로 공개합니다.
