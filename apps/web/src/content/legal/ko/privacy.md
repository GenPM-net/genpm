## 2. 처리하는 정보, 목적과 근거

| 정보 | 목적 | 법적 근거 | 보관 기간 |
|---|---|---|---|
| GitHub ID, 로그인, 이름, 아바타, 조직(로그인 시) | 계정 생성과 유지, 각 패키지의 게시자 표시, 여러분의 스코프에 대한 게시 권한 부여 | 계약 이행(GDPR 제6.1.b조): 서비스 약관 | 계정이 존재하는 동안 |
| GitHub 계정 이메일(공개되지 않음) | 패키지 관련 보안 및 서비스 공지 | 계약 및 생태계 보안에 대한 정당한 이익(제6.1.f조) | 계정이 존재하는 동안 |
| API 토큰(해시만 저장) | CLI와 CI 인증 | 계약 | 만료되거나 취소할 때까지 |
| 게시된 패키지: 매니페스트, 저장소, 커밋, GitHub 로그인 | 레지스트리 운영: 패키지 검색, 검증, 설치 | 계약 | 무기한: 게시된 버전은 변경할 수 없어 이를 사용하는 프로젝트가 계속 검증 가능해야 함(§6 참고) |
| 설치 이벤트: 패키지, 버전, 클라이언트(`cli`/`mcp`), CLI 버전, 국가(IP에서 도출하며 IP는 저장하지 않음) | 공개 설치 횟수와 집계 통계 | 레지스트리 이용 측정에 대한 정당한 이익 | 일 단위로 집계, 개별 이벤트는 90일 |
| 매일 바뀌는 솔트로 해시한 IP 주소 | 요청 한도 제한과 남용 방지 | 서비스 보안에 대한 정당한 이익(제6.1.f조, 전문 49) | 최대 30일 |
| 서버 기술 로그(Cloudflare Workers) | 오류와 공격 진단 | 서비스 보안과 연속성에 대한 정당한 이익 | 최대 7일 |
| 스폰서·기업용 양식: 이메일, 회사, 팀 규모, IDE, 메시지 | 요청에 대한 답변 | 여러분의 요청에 따른 계약 전 조치(제6.1.b조) | 합의에 이르지 않으면 12개월 |
| 패키지 신고: 계정, 패키지, 사유, 설명 | 신고된 콘텐츠 검토와 결정 통지 | EU 디지털서비스법 제16조에 따른 법적 의무(GDPR 제6.1.c조) | 결정 후 2년 |
| 보내 주신 이메일 | 요청 또는 권리 행사 처리 | 답변에 대한 정당한 이익 또는 해당하는 경우 법적 의무 | 필요한 기간과 그 후 최대 2년 |

**절대 처리하지 않는 정보:** 프로젝트 내용, `.env` 파일, 환경 변수 값. 광고나 사이트 간 추적 쿠키는 사용하지 않습니다. 웹 분석은 자체적으로 하며 쿠키와 IP를 사용하지 않습니다([쿠키 정책](/cookies) 참고).

**CLI와 MCP 원격 측정:** `GENPM_TELEMETRY=0` 또는 `DO_NOT_TRACK=1`을 설정하면 클라이언트가 `client=none`을 보내고 레지스트리는 이벤트를 저장하지 않습니다. 이 방법으로 언제든 거부할 수 있습니다.

여러분에게 법적 효과를 미치는 결정을 자동화된 처리만으로 내리지 않습니다(GDPR 제22조). 자동 스캐너가 패키지를 검토 대상으로 지정할 수는 있지만, 철회의 최종 결정은 사람이 내립니다([패키지 정책](/policy) 참고).

계정을 만들려면 GitHub 정보 제공이 필요합니다. 제공하지 않으면 게시할 수 없지만, 계정이 필요 없는 패키지 검색과 설치는 계속 이용할 수 있습니다.

## 3. 수령자와 수탁자

여러분의 정보를 제3자에게 판매하거나 공유하지 않습니다. 다음 업체가 처리 위탁 계약(GDPR 제28조)에 따라 우리를 대신해 정보를 처리합니다.

| 업체 | 서비스 | 위치 |
|---|---|---|
| Cloudflare, Inc. | 호스팅(Workers), 데이터베이스(D1), 전송 네트워크, 봇 방지(Turnstile), 집계 분석 | EU 및 미국 |
| Piensa Solutions (Arsys Internet, S.L.U.) | 도메인과 이메일 | 스페인 |

**GitHub, Inc.**는 여러분이 GitHub로 로그인할 때와 레지스트리가 공개 저장소를 읽을 때 독립적인 처리자로서 행동하며, 자체 [개인정보 처리방침](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)이 적용됩니다.

공개 패키지 정보(이름, 버전, 저장소, 게시자의 GitHub 로그인)는 서비스의 목적상 모든 방문자와 레지스트리를 사용하는 AI 에이전트에게 표시됩니다.

법률이 요구하는 경우에만 당국에 정보를 제공합니다.

## 4. 국외 이전

Cloudflare, Inc.와 GitHub, Inc.는 2023년 7월 10일 유럽연합 집행위원회의 적정성 결정(GDPR 제45조)으로 인정된 EU-미국 데이터 프라이버시 프레임워크에 참여하고 있습니다. 또한 계약에 집행위원회의 표준 계약 조항(GDPR 제46조)이 포함되어 있습니다.

## 5. 여러분의 권리

언제든 {{email}}으로 제목을 "[PRIVACY]"로 하여 이메일을 보내 **열람, 정정, 삭제, 처리 반대, 처리 제한, 이동** 권리를 행사하고, 제공한 동의를 철회할 수 있습니다. 1개월 이내에 답변합니다(GDPR 제12.3조). 보내 주신 내용으로 본인 확인이 안 되면 필요한 최소한의 정보를 요청합니다.

요청이 제대로 처리되지 않았다고 생각되면 **스페인 개인정보보호청**([www.aepd.es](https://www.aepd.es), C/ Jorge Juan 6, 28001 Madrid) 또는 거주 국가의 감독 기관에 민원을 제기할 수 있습니다.

## 6. 계정 해지

계정 해지를 요청하면 30일 이내에 개인정보를 익명화하며, 백업은 추가 30일 이내에 덮어씁니다. 게시한 패키지는 다른 프로젝트가 의존하고 있고 버전을 변경할 수 없으므로 시스템 계정에 할당된 채 계속 제공됩니다. 각 패키지의 GitHub 저장소 URL(로그인이 포함될 수 있음)은 게시된 패키지의 일부입니다. 더 이상 설치되지 않기를 원하면 계정을 해지하기 전에 철회(*yank*)하세요.

## 7. 미성년자

GenPM은 개발자를 위한 서비스입니다. 계정을 만들려면 만 14세 이상이어야 합니다(LOPDGDD 제7조). 그 미만이면 부모나 법정대리인의 동의가 필요합니다.

## 8. 보안

위험에 맞는 기술적·조직적 조치를 적용합니다. 전송 구간 암호화(HSTS를 적용한 HTTPS), 해시로만 저장하는 토큰, `HttpOnly`·`Secure` 쿠키, 가명 처리한 IP 주소, 2단계 인증으로 제한한 접근, 서명된 매니페스트. 침해로 여러분의 권리가 위험해지면 72시간 이내에 AEPD에 신고하고, 필요한 경우 여러분에게도 알립니다(GDPR 제33조, 제34조).

## 9. 변경

이 방침을 중대하게 변경하면 genpm.net에 공지하고, 계정이 있다면 사전에 이메일로도 알립니다.
