## 2. 我们处理什么、为什么以及依据什么

| 数据 | 目的 | 法律基础 | 保存期限 |
|---|---|---|---|
| GitHub ID、登录名、姓名、头像和所属组织（登录时） | 创建和维护你的账户，显示每个包的发布者，并授权你在自己的作用域中发布 | 履行合同（GDPR 第 6.1.b 条）：服务条款 | 账户存续期间 |
| 你 GitHub 账户的邮箱（从不显示） | 与你的包相关的安全和服务通知 | 合同以及维护生态安全的正当利益（第 6.1.f 条） | 账户存续期间 |
| API 令牌（只存储其哈希值） | 认证 CLI 和 CI | 合同 | 直到过期或你撤销 |
| 已发布的包：清单、仓库、提交以及你的 GitHub 登录名 | 运营注册表：搜索、验证和安装包 | 合同 | 无限期：已发布版本不可变更，以便使用它们的项目仍可验证（见 §6） |
| 安装事件：包、版本、客户端（`cli`/`mcp`）、CLI 版本和国家（由 IP 推断，IP 本身不保存） | 公开的安装计数和汇总统计 | 衡量注册表使用情况的正当利益 | 按天汇总；单个事件保存 90 天 |
| 使用每日轮换的盐值哈希处理后的 IP 地址 | 速率限制和防止滥用 | 服务安全的正当利益（第 6.1.f 条，前言第 49 条） | 最长 30 天 |
| 服务器技术日志（Cloudflare Workers） | 诊断错误和攻击 | 服务安全与连续性的正当利益 | 最长 7 天 |
| 网站分析：搜索词、查看的软件包、语言和路径（不含 IP 或任何标识符） | 了解大家搜索和使用什么，以改进服务 | 以汇总方式衡量使用情况的正当利益（第 6.1.f 条） | 3 个月（Cloudflare Analytics Engine） |
| 赞助或企业表单：邮箱、公司、团队规模、IDE 和留言 | 回复你的请求 | 应你的要求采取的合同前措施（第 6.1.b 条） | 12 个月，除非达成协议 |
| 包举报：你的账户、包、理由和你的描述 | 审查被举报的内容并告知决定 | 欧盟《数字服务法》第 16 条规定的法律义务（GDPR 第 6.1.c 条） | 决定后 2 年 |
| 你发给我们的邮件 | 处理你的请求或权利行使 | 回复你的正当利益，或在适用时的法律义务 | 所需期间及之后最长 2 年 |

这些期限会自动执行：每日任务会删除或匿名化已到期的数据。

**我们从不处理的内容：** 你项目的内容、你的 `.env` 文件或环境变量的值。我们不使用广告或跨站跟踪 Cookie，你的浏览器也不会为分析发送任何数据：我们在服务器上统计你请求的页面（见 [Cookie 政策](/cookies)）。

**CLI 和 MCP 遥测：** 设置 `GENPM_TELEMETRY=0` 或 `DO_NOT_TRACK=1` 后，客户端会发送 `client=none`，注册表不会保存该事件。你可以随时通过这种方式表示反对。

我们不会仅基于自动化处理作出对你产生法律效力的决定（GDPR 第 22 条）。自动扫描可能会把某个包置于审核状态，但最终撤回由人工决定（见[包政策](/policy)）。

创建账户需要提供你的 GitHub 数据；不提供则无法发布，但你仍可以搜索和安装包，这无需账户。

## 3. 接收方和处理者

我们不会出售你的数据，也不会与第三方共享。以下服务商依据数据处理协议（GDPR 第 28 条）代表我们处理数据：

| 服务商 | 服务 | 所在地 |
|---|---|---|
| Cloudflare, Inc. | 托管（Workers）、数据库（D1）、分发网络、反机器人保护（Turnstile）和汇总统计 | 欧盟和美国 |
| Piensa Solutions（Arsys Internet, S.L.U.） | 域名和邮箱 | 西班牙 |

当你使用 GitHub 登录以及注册表读取公开仓库时，**GitHub, Inc.** 作为独立的控制者行事，适用其自身的[隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)。

包的公开数据（名称、版本、仓库以及发布者的 GitHub 登录名）会向所有访问者以及使用注册表的 AI 智能体展示，因为这正是该服务的目的。

只有在法律要求时，我们才会向主管机关披露数据。

## 4. 国际传输

Cloudflare, Inc. 和 GitHub, Inc. 参加了欧盟-美国数据隐私框架，该框架已获欧盟委员会 2023 年 7 月 10 日的充分性认定（GDPR 第 45 条）。它们的合同还包含欧盟委员会的标准合同条款（GDPR 第 46 条）。

## 5. 你的权利

你可以随时发送邮件至 {{email}}，主题写“[PRIVACY]”，行使**访问、更正、删除、反对、限制处理和数据可携带**的权利，并撤回你给出的任何同意。我们会在一个月内答复（GDPR 第 12.3 条）。如果凭你提供的信息无法识别你的身份，我们会请你提供最少必要的信息。

如果你认为我们没有妥善处理你的请求，可以向**西班牙数据保护局**（[www.aepd.es](https://www.aepd.es)，C/ Jorge Juan 6, 28001 Madrid）或你居住国的主管机关投诉。

## 6. 注销账户

如果你要求注销账户，我们会在 30 天内对你的个人数据进行匿名化处理；备份会在之后 30 天内被覆盖。你已发布的包会继续提供，并归属于一个系统账户，因为其他项目依赖它们且其版本不可变更。每个包的 GitHub 仓库 URL（可能包含你的登录名）是已发布包的一部分；如果你希望它们不再被安装，请在注销账户前撤回它们。

## 7. 未成年人

GenPM 是面向开发者的服务。创建账户须年满 16 周岁：这是 GDPR 第 8 条规定的一般年龄，也是西班牙《数字环境中未成年人保护组织法草案》所定的年龄（该草案将提高 LOPDGDD 第 7 条规定的 14 岁）。我们不接受未满该年龄者的账户；一经发现，将关闭账户并删除其数据。

## 8. 安全

我们采取与风险相适应的技术和组织措施：传输加密（带 HSTS 的 HTTPS）、令牌只以哈希形式存储、`HttpOnly` 和 `Secure` Cookie、IP 地址假名化、通过双重身份验证限制访问，以及签名清单。如果数据泄露危及你的权利，我们会在 72 小时内通知 AEPD，并在需要时通知你（GDPR 第 33 条和第 34 条）。

## 9. 变更

如果我们对本政策作出重大修改，会提前在 genpm.net 上公布；如果你有账户，还会通过邮件通知。
