本条款适用于由 {{name}}（完整信息见[法律声明](/legal)）提供的 genpm.net、注册表 API（`api.genpm.net`）、`genpm` CLI 和 `@genpm-net/mcp` 服务器（统称“GenPM”）。创建账户或发布包即表示你接受本条款。搜索和安装包无需账户。GenPM 处于**公开测试阶段**，免费提供。

## 1. GenPM 的功能

GenPM 是一个注册表，它为托管在公开 Git 仓库中的包索引清单，并帮助你把它们的代码、面向 AI 智能体的规则和 MCP 配置复制到你的项目中。注册表只存储元数据；代码直接从 Git 仓库下载，并固定在特定的提交上。

## 2. 账户

- 你使用 GitHub 账户登录，且必须年满 16 周岁。
- 你对账户及 API 令牌的活动负责。请妥善保密，如有泄露请撤销。
- 你可以随时发送邮件至 {{email}} 注销账户；对你的包的影响见[隐私政策](/privacy#6-注销账户)。

## 3. 发布包

发布包时：

- 你声明有权按所述许可证分发其代码，且代码符合[包政策](/policy)和法律。
- 你授予 GenPM 一项免费、全球范围、非独占的许可，可在提供服务所需的范围内存储、索引、展示和分发包的元数据、README 及 AI 规则。代码本身仍受包的许可证约束。
- 你接受已发布的版本**不可变更**：你可以撤回（*yank*）它们，但它们不会从索引中删除，以便已使用它们的项目仍可验证。

## 4. 使用包

包由第三方发布。GenPM 会验证其完整性、自动扫描，并且从不运行其代码，但无法保证它们没有错误或恶意代码。请检查你安装的内容：代码会成为你项目的一部分。其使用受各包的许可证约束。

## 5. 可接受的使用

禁止：将 GenPM 用于违法活动；发布恶意软件或侵犯第三方权利的内容；冒充他人、品牌或发布者；抢注名称以转售或阻止他人使用；超出速率限制抓取 API 数据；攻击服务或使其过载。

## 6. 内容审核

为保护安装包的用户，GenPM 执行[包政策](/policy)。该政策是本条款的一部分，并按照条例（EU）2022/2065（《数字服务法》）第 14 条的要求，说明哪些内容不被允许、如何检测（自动扫描和人工审核）、可能采取的措施（审核、撤回版本、暂停账户）以及如何申诉。当我们对你的内容或账户采取措施时，会说明理由。

## 7. 服务的可用性和变更

GenPM 按现状提供，处于测试阶段且免费。为改进服务或出于安全原因，我们可能修改、限制或中断功能；如对发布者有重大影响，我们会提前合理通知。

## 8. 责任

对于第三方发布的包中的代码、对服务的不当使用或我们无法控制的中断所造成的损害，GenPM 不承担责任。本条款中的任何内容均不限制对故意或重大过失、人身伤害的责任，也不限制消费者保护法（西班牙第 1/2007 号皇家立法令）赋予你的权利。

## 9. 暂停和注销

对于严重违反本条款或包政策的账户，我们可以在说明理由并提供申诉机会的前提下暂停或注销。你可以随时注销账户。

## 10. 条款变更

重大变更会在生效前至少 30 天在 genpm.net 上公布；如果你有账户，还会通过邮件通知。如不同意，你可以在该日期前注销账户。
