## 1. Ce que fait GenPM

GenPM est un registry qui indexe les manifestes de paquets hébergés dans des dépôts Git publics et vous aide à copier dans votre projet leur code, leurs règles pour agents IA et leur configuration MCP. Le registry ne stocke que des métadonnées ; le code est téléchargé directement depuis le dépôt Git, épinglé sur un commit précis.

- Vous êtes responsable de l’activité de votre compte et de vos jetons d’API. Gardez-les secrets et révoquez-les s’ils fuitent.
- Vous pouvez fermer votre compte à tout moment en écrivant à {{email}} ; les conséquences pour vos paquets sont expliquées dans la [Politique de confidentialité](/privacy#6-fermeture-de-votre-compte).

## 3. Publier des paquets

Quand vous publiez un paquet :

- Vous déclarez avoir le droit de distribuer son code sous la licence indiquée et qu’il respecte la [Politique des paquets](/policy) et la loi.
- Vous accordez à GenPM une licence gratuite, mondiale et non exclusive pour stocker, indexer, afficher et distribuer les métadonnées du paquet, son README et ses règles IA, dans la mesure nécessaire à la fourniture du service. Le code reste régi par la licence du paquet.
- Vous acceptez que les versions publiées soient **immuables** : vous pouvez les retirer (*yank*), mais elles ne sont pas supprimées de l’index, pour que les projets qui les utilisent restent vérifiables.

## 4. Utiliser des paquets

Les paquets sont publiés par des tiers. GenPM vérifie leur intégrité, les analyse automatiquement et n’exécute jamais leur code, mais ne peut pas garantir qu’ils soient exempts d’erreurs ou de code malveillant. Vérifiez ce que vous installez : le code fait partie de votre projet. Son utilisation est régie par la licence de chaque paquet.
