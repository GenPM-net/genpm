本規約は、{{name}}（詳細は[法的情報](/legal)を参照）が提供する genpm.net、レジストリ API（`api.genpm.net`）、CLI `genpm`、サーバー `@genpm-net/mcp`（以下まとめて「GenPM」）の利用に適用されます。アカウントを作成するか、パッケージを公開した時点で、本規約に同意したものとみなします。パッケージの検索とインストールにアカウントは不要です。GenPM は**パブリックベータ**であり、無料です。

## 1. GenPM の役割

GenPM は、公開 Git リポジトリでホストされているパッケージのマニフェストをインデックス化し、そのコード、AI エージェント向けルール、MCP 設定をあなたのプロジェクトにコピーするのを手助けするレジストリです。レジストリはメタデータのみを保存し、コードは特定のコミットに固定された状態で Git リポジトリから直接ダウンロードされます。

## 2. アカウント

- GitHub アカウントでサインインします。16 歳以上である必要があります。
- アカウントと API トークンでの活動については、あなたが責任を負います。トークンは秘密に保ち、漏えいした場合は取り消してください。
- {{email}} に連絡すれば、いつでもアカウントを削除できます。パッケージへの影響は[プライバシーポリシー](/privacy#6-アカウントの削除)で説明しています。

## 3. パッケージの公開

パッケージを公開するとき、あなたは次のことに同意します。

- 記載したライセンスのもとでコードを配布する権利を持ち、そのコードが[パッケージポリシー](/policy)と法令に適合していることを表明します。
- サービス提供に必要な範囲で、パッケージのメタデータ、README、AI ルールを保存・インデックス化・表示・配布するための、無償・全世界・非独占的なライセンスを GenPM に付与します。コード自体には引き続きパッケージのライセンスが適用されます。
- 公開したバージョンは**変更できない**ことを受け入れます。取り下げ（*yank*）はできますが、すでに利用しているプロジェクトが検証可能であり続けるよう、インデックスからは削除されません。

## 4. パッケージの利用

パッケージは第三者が公開しています。GenPM は完全性を検証し、自動でスキャンし、そのコードを実行することはありませんが、不具合や悪意のあるコードがないことは保証できません。インストールするものは必ず確認してください。コードはあなたのプロジェクトの一部になります。利用には各パッケージのライセンスが適用されます。

## 5. 禁止事項

次の行為を禁止します。違法な目的での GenPM の利用、マルウェアや第三者の権利を侵害するコンテンツの公開、他人・ブランド・公開者へのなりすまし、転売や妨害を目的とした名前の占有、利用制限を超える API からのデータ取得、サービスへの攻撃や過負荷。

## 6. コンテンツのモデレーション

パッケージをインストールする人を守るため、GenPM は[パッケージポリシー](/policy)を適用します。このポリシーは本規約の一部であり、規則（EU）2022/2065（デジタルサービス法）第 14 条が求めるとおり、禁止されるコンテンツ、その検出方法（自動スキャンと人による確認）、取りうる措置（確認、バージョンの取り下げ、アカウントの停止）、異議申し立ての方法を定めています。あなたのコンテンツやアカウントに措置を講じる場合は、その理由を説明します。

## 7. サービスの提供と変更

GenPM は現状のまま、ベータ版として無料で提供されます。サービス改善やセキュリティ上の理由で機能を変更・制限・停止することがあります。公開者に大きな影響がある場合は、合理的な期間をもって事前に通知します。

## 8. 責任

GenPM は、第三者が公開したパッケージのコード、サービスの不正利用、当方の管理外の中断によって生じた損害について責任を負いません。ただし本規約のいかなる条項も、故意または重過失、人身損害に対する責任、および消費者保護法（スペイン王令 1/2007）があなたに認める権利を制限するものではありません。

## 9. 停止と削除

本規約またはパッケージポリシーに重大な違反があるアカウントは、理由を示し、異議申し立ての機会を設けたうえで停止または削除することがあります。あなたはいつでもアカウントを削除できます。

## 10. 本規約の変更

重要な変更は、発効の少なくとも 30 日前に genpm.net で告知し、アカウントをお持ちの場合はメールでもお知らせします。同意できない場合は、その日までにアカウントを削除できます。

## 11. 言語、準拠法、管轄

本規約は複数の言語で提供されますが、相違がある場合はスペイン語版が優先されます。準拠法はスペイン法です。消費者として行動する場合はあなたの居住地の裁判所が、それ以外の場合は {{city}} の裁判所が管轄します。訴訟の前に {{email}} までご連絡ください。友好的な解決を目指します。
