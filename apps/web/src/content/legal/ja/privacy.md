## 2. 処理するデータ、目的、法的根拠

| データ | 目的 | 法的根拠 | 保存期間 |
|---|---|---|---|
| GitHub の ID、ログイン名、氏名、アバター、所属組織（サインイン時） | アカウントの作成と維持、各パッケージの公開者の表示、あなたのスコープへの公開の許可 | 契約の履行（GDPR 第 6.1.b 条）: 利用規約 | アカウントが存在する間 |
| GitHub アカウントのメールアドレス（表示しません） | パッケージに関するセキュリティ・サービス上のお知らせ | 契約、およびエコシステムの安全に関する正当な利益（第 6.1.f 条） | アカウントが存在する間 |
| API トークン（ハッシュのみ保存） | CLI と CI の認証 | 契約 | 失効または取り消しまで |
| 公開パッケージ: マニフェスト、リポジトリ、コミット、あなたの GitHub ログイン名 | レジストリの運営: パッケージの検索・検証・インストール | 契約 | 無期限: 利用中のプロジェクトが検証可能であり続けるよう、公開バージョンは変更できません（§6 を参照） |
| インストールイベント: パッケージ、バージョン、クライアント（`cli`/`mcp`）、CLI のバージョン、国（IP から推定し、IP 自体は保存しません） | 公開のインストール数と集計統計 | レジストリの利用状況を測定する正当な利益 | 日単位で集計。個別イベントは 90 日 |
| 日替わりのソルトでハッシュ化した IP アドレス | レート制限と不正利用の防止 | サービスの安全に関する正当な利益（第 6.1.f 条、前文 49） | 最長 30 日 |
| サーバーの技術ログ（Cloudflare Workers） | エラーや攻撃の診断 | サービスの安全と継続に関する正当な利益 | 最長 7 日 |
| Web 分析: ページビュー、検索語、閲覧したパッケージ、言語、パス、参照元ドメイン、キャンペーン、国、ボットかどうか（IP や識別子は含まない） | 何が検索・利用され、訪問がどこから来るかを把握してサービスを改善する | 利用状況を集計で測定する正当な利益（第 6.1.f 条） | 3 か月（Cloudflare Analytics Engine） |
| **任意の分析に同意した場合のみ:** クリック、スクロール、閲覧ページ、フォーム入力を隠したセッション記録、ランダムなブラウザー識別子、ブラウザーと端末の種類（PostHog）。アカウント関連のページは記録せず、IP は転送しません | ヒートマップを作成し、つまずきやすい箇所を見つけてサイトを改善する | 同意（GDPR 第 6.1.a 条、LSSI-CE 第 22.2 条）。フッターの「Cookie の設定」からいつでも撤回できます | イベント 12 か月、記録 30 日 |
| スポンサー・企業向けフォーム: メール、会社名、チーム規模、IDE、メッセージ | お問い合わせへの回答 | あなたの依頼による契約前の措置（第 6.1.b 条） | 合意に至らない場合は 12 か月 |
| パッケージの報告: あなたのアカウント、パッケージ、理由、説明 | 報告されたコンテンツの確認と判断の通知 | EU デジタルサービス法第 16 条に基づく法的義務（GDPR 第 6.1.c 条） | 判断から 2 年 |
| あなたから届いたメール | お問い合わせや権利行使への対応 | 回答に関する正当な利益、または該当する場合は法的義務 | 必要な期間と、その後最長 2 年 |

これらの保存期間は自動で適用されます。期限を過ぎたデータは毎日の処理で削除または匿名化されます。

**処理しないもの:** あなたのプロジェクトの中身、`.env` ファイル、環境変数の値。広告やサイトをまたいだ追跡のための Cookie は使用しません。任意の分析に同意しない限り、分析のためにブラウザから何かを送信させることはありません。分析は、あなたがリクエストしたページをもとにサーバー側で集計します（[Cookie ポリシー](/cookies)を参照）。

**CLI と MCP のテレメトリー:** `GENPM_TELEMETRY=0` または `DO_NOT_TRACK=1` を設定すると、クライアントは `client=none` を送り、レジストリはイベントを保存しません。いつでもこの方法で異議を申し立てられます。

あなたに法的効果を及ぼす、自動処理のみに基づく決定は行いません（GDPR 第 22 条）。自動スキャンがパッケージを確認待ちにすることはありますが、最終的な取り下げは人が判断します（[パッケージポリシー](/policy)を参照）。

アカウントの作成には GitHub のデータが必要です。提供しない場合は公開できませんが、アカウント不要のパッケージの検索とインストールは引き続き利用できます。

## 3. 提供先と処理委託先

あなたのデータを販売したり第三者と共有したりすることはありません。以下の事業者が、データ処理契約（GDPR 第 28 条）に基づき当方に代わって処理します。

| 事業者 | サービス | 所在地 |
|---|---|---|
| Cloudflare, Inc. | ホスティング（Workers）、データベース（D1）、配信ネットワーク、ボット対策（Turnstile）、集計統計 | EU と米国 |
| PostHog, Inc. | 任意の Web 分析（ヒートマップとセッション記録）。同意した場合のみ | EU（ドイツ・フランクフルト） |
| Piensa Solutions（Arsys Internet, S.L.U.） | ドメインとメール | スペイン |

**GitHub, Inc.** は、あなたが GitHub でサインインするとき、およびレジストリが公開リポジトリを読むときに独立した管理者として行動し、同社の[プライバシーステートメント](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)が適用されます。

パッケージの公開データ（名前、バージョン、リポジトリ、公開者の GitHub ログイン名）は、サービスの目的上、すべての訪問者とレジストリを使う AI エージェントに表示されます。

当局へのデータ開示は、法律で求められた場合に限ります。

## 4. 国際移転

Cloudflare, Inc. と GitHub, Inc. は、2023 年 7 月 10 日の欧州委員会の十分性認定（GDPR 第 45 条）で承認された EU-米国データプライバシーフレームワークに参加しています。両社の契約には、欧州委員会の標準契約条項（GDPR 第 46 条）も含まれます。 PostHog はデータを EU に保管し、米国からアクセスする場合は欧州委員会の標準契約条項（GDPR 第 46 条）に基づきます。

## 5. あなたの権利

件名を「[PRIVACY]」として {{email}} に連絡すれば、いつでも**アクセス、訂正、削除、異議、制限、データポータビリティ**の権利を行使し、与えた同意を撤回できます。1 か月以内に回答します（GDPR 第 12.3 条）。送られた情報で本人確認ができない場合は、必要最小限の情報をお願いします。

対応が適切でないと考える場合は、**スペインデータ保護庁**（[www.aepd.es](https://www.aepd.es)、C/ Jorge Juan 6, 28001 Madrid）またはお住まいの国の当局に苦情を申し立てられます。

## 6. アカウントの削除

アカウントの削除を依頼された場合、30 日以内に個人データを匿名化し、バックアップもさらに 30 日以内に上書きされます。あなたが公開したパッケージは、他のプロジェクトが依存しており、バージョンが変更できないため、システムアカウントに割り当てたうえで引き続き提供されます。各パッケージの GitHub リポジトリの URL（あなたのログイン名を含む場合があります）は公開パッケージの一部です。今後インストールされないようにしたい場合は、アカウントを削除する前に取り下げてください。

## 7. 未成年者

GenPM は開発者向けのサービスです。アカウントの作成には 16 歳以上である必要があります。これは GDPR 第 8 条の一般的な年齢であり、LOPDGDD 第 7 条の 14 歳を引き上げるスペインの「デジタル環境における未成年者保護組織法案」が定める年齢でもあります。それ未満の方のアカウントは受け付けず、判明した場合はアカウントを閉鎖しデータを削除します。

## 8. セキュリティ

リスクに応じた技術的・組織的な措置を講じています。通信の暗号化（HSTS 付き HTTPS）、ハッシュのみでのトークン保存、`HttpOnly` と `Secure` の Cookie、IP アドレスの仮名化、二要素認証によるアクセス制限、署名付きマニフェストです。侵害があなたの権利を脅かす場合は、72 時間以内に AEPD に通知し、必要に応じてあなたにもお知らせします（GDPR 第 33 条・第 34 条）。

## 9. 変更

本ポリシーを大きく変更する場合は、genpm.net で告知し、アカウントをお持ちの場合は事前にメールでお知らせします。
