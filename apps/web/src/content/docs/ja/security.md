GenPM は設計段階から安全で、誰でも検証できます。「100 % 安全」とは決して約束しません。その代わり 10 個の不変条件を保証し、それぞれにすべてのリリースを止めるテストがあります。

1. **完全性**: インストールされるバイト列は、コミット `c` のツリーそのものです。ブランチではありません。
2. **実行ゼロ**: ライフサイクルスクリプト、Git フック、サブモジュール、フィルターはありません。
3. **閉じ込め**: 書き込みはプロジェクト内の、計画したパスだけです。
4. **実行ファイルなし**: 注入するファイルはモード `0644` で書き込みます。
5. **同意**: あなたの同意なしに MCP 設定、npm のインストール、上書きは行いません。
6. **シークレット**: GenPM は `.env` の値を読みません。
7. **レジストリの権威**: 公開時に読むのは GitHub で、クライアントが送る内容ではありません。
8. **署名付きマニフェスト**: CLI は Ed25519 で署名されたマニフェストだけをインストールします。
9. **不変性**: 公開済みのバージョンは決して変わりません。
10. **テナント分離**: どのクエリもレジストリの境界を越えません。

同じ決定的なスキャナーがレジストリ（公開時）と CLI（毎回のインストール時）で動くため、レジストリが侵害されただけではこれを回避できません。

## 脆弱性の報告

件名を `[SECURITY]` にして **hello@genpm.net** に送るか、GitHub Private Vulnerability Reporting を使ってください。最初の返信は 48 時間以内です。詳しくは [/security](/security) を参照してください。
