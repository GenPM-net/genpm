GenPM 패키지는 하나의 커밋에 고정되어 함께 전달되는 세 개의 계층으로 이루어집니다.

| 계층 | 내용 | 위치 |
|---|---|---|
| **코드** | 모듈의 소스 코드 | `d`, 예: `src/lib/auth/` |
| **컨텍스트** | AI 에이전트를 위한 규칙(`x`) | `<d>/AGENTS.md`와 범위가 지정된 IDE 규칙 파일 |
| **연결** | 모듈에 필요한 MCP 서버(`m`) | `.mcp.json`, `.cursor/mcp.json` 등. 동의한 경우에만 |

## 레지스트리는 메타데이터만 저장

레지스트리는 매니페스트를 색인하고 Git을 가리킵니다. 설치할 때 CLI는 **Git 호스트에서 직접** 정확한 커밋(`c`)의 코드를 내려받아 검증합니다. `git rev-parse HEAD`가 `c`와 같아야 하고, 모든 파일이 커밋의 트리와 일치해야 합니다.

## 실행 전에 계획

`plan()`은 프로젝트에 아무것도 쓰지 않습니다. 의존성을 해석하고, 전역 캐시에 내려받고, 파일을 스캔합니다. `apply()`는 저널을 통해 쓰며, 하나라도 실패하면 모두 되돌립니다.

## 스크립트는 절대 없음

GenPM에는 라이프사이클 스크립트가 없습니다. 패키지의 어떤 것도 여러분의 컴퓨터에서 실행되지 않습니다. 다른 도구가 자동으로 실행하는 파일(`postinstall`, `.npmrc`, `.envrc`, `.vscode/tasks.json` 등)은 거부됩니다.
