GenPM은 설계부터 안전하며 누구나 검증할 수 있습니다. "100% 안전"을 약속하지는 않습니다. 대신 열 가지 불변 조건을 보장하며, 각각에는 모든 릴리스를 막는 테스트가 있습니다.

1. **무결성**: 설치되는 바이트는 커밋 `c`의 트리와 정확히 같습니다. 브랜치에서 오지 않습니다.
2. **실행 없음**: 라이프사이클 스크립트, Git 훅, 서브모듈, 필터가 없습니다.
3. **범위 제한**: 쓰기는 프로젝트 안, 계획된 경로에서만 일어납니다.
4. **실행 파일 없음**: 주입되는 파일은 `0644` 권한으로 작성됩니다.
5. **동의**: 여러분의 동의 없이 MCP 설정, npm 설치, 덮어쓰기를 하지 않습니다.
6. **시크릿**: GenPM은 `.env`의 값을 읽지 않습니다.
7. **레지스트리 권한**: 게시할 때는 클라이언트가 보낸 내용이 아니라 GitHub를 읽습니다.
8. **서명된 매니페스트**: CLI는 Ed25519로 서명된 매니페스트만 설치합니다.
9. **불변성**: 게시된 버전은 절대 바뀌지 않습니다.
10. **테넌트 격리**: 어떤 쿼리도 레지스트리 경계를 넘지 않습니다.

같은 결정적 스캐너가 레지스트리(게시 시)와 CLI(설치할 때마다)에서 실행되므로, 레지스트리가 침해되더라도 이를 우회할 수 없습니다.

## 취약점 신고

제목을 `[SECURITY]`로 해서 **hello@genpm.net**으로 보내거나 GitHub Private Vulnerability Reporting을 사용하세요. 첫 답변은 48시간 안에 드립니다. 자세한 내용은 [/security](/security)를 참고하세요.
