GenPM 从设计上就是安全的，并且任何人都可以验证。它从不承诺“100% 安全”，而是保证十条不变量，每一条都有一个会阻止任何发布的测试：

1. **完整性**：安装的字节与提交 `c` 的文件树完全一致，绝不来自分支。
2. **零执行**：没有生命周期脚本、Git 钩子、子模块或过滤器。
3. **限定范围**：只在项目内、计划中的路径上写入。
4. **无可执行文件**：注入的文件以 `0644` 权限写入。
5. **征得同意**：未经你同意，不写入 MCP 配置、不安装 npm 包、不覆盖文件。
6. **密钥**：GenPM 从不读取 `.env` 中的值。
7. **注册表权威**：发布时读取的是 GitHub，而不是客户端发送的内容。
8. **签名清单**：CLI 只安装经过 Ed25519 签名的清单。
9. **不可变**：已发布的版本永远不会改变。
10. **租户隔离**：任何查询都不会跨越注册表。

同一个确定性扫描器同时运行在注册表（发布时）和 CLI（每次安装时）中，因此仅攻破注册表并不足以绕过它。

发送邮件到 **hello@genpm.net**，主题写 `[SECURITY]`，或使用 GitHub Private Vulnerability Reporting。我们会在 48 小时内首次回复。详见 [/security](/security)。
